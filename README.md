## Description

Basic social messaging app demo with dummy accounts. 

### Features:

1.1 Essential

- Sign up, log in/out, 
- Add contacts and keep a contact list
- Send and receive messages
- Create a group chat
- Web push notifications
- Block users

1.2 Extras:

- Read receipts
- Attach files, docs, images
- Quote messages
- 'is typing' indicator
- GIFs and emojis
- message dating
- conversation search 
- YouTube-specific metadata provider

- posted URL previews	
- Block/unblock users
- ~~Contact requests~~
- ~~Invisible mode~~	
- ~~Group@mentions~~
-~~Individual group read receipts~~
- ~~Light/dark/system theme~~
- ~~Notification sounds~~
- ~~Progressive Web App~~
- ~~Password recovery~~

1.3 Security:

- Image signature integration
- SSRF and restricted IP verification
- Malicious redirect tests
- Shared request deadline
- Sensitive URL filtering
- Authentication and membership verification
- Database permissions and RLS verification
- Final automated tests
- Normal preview and cache verification
